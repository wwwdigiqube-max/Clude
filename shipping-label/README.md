# برچسب‌ساز سفارش دیجی‌کیوب

فایل `label-maker.html` را در هر مرورگری (کامپیوتر یا گوشی) باز کنید؛ به اینترنت هم نیاز ندارد.

1. پیام سفارش مشتری را در کادر اول بچسبانید → نام، آدرس، تلفن و کدپستی خودکار پر می‌شوند.
2. اگر لازم بود اصلاح کنید.
3. «چاپ» یا «دانلود عکس» بزنید؛ یا به «لیست امروز» اضافه کنید و آخر کار همه را یک‌جا چاپ کنید.

اطلاعات فرستنده و اندازه کاغذ از بخش «تنظیمات» قابل تغییر است.

## برای توسعه
- سورس: `src/index.html` — تصاویر: `assets/` — فونت وزیرمتن و کتابخانه html-to-image: `vendor/`
- ساخت فایل نهایی تک‌فایلی: `python3 build.py`
